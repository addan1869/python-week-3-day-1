Week 3 - Day 1: Classes, Objects and Constructors in Python
Overview

This repository contains the Python programs completed during Week 3 - Day 1 of my internship. The focus of this day was learning the fundamentals of Object-Oriented Programming (OOP) in Python, including classes, objects, instance methods, constructors (__init__()), and the use of the self keyword.

Topics Covered
Introduction to Object-Oriented Programming (OOP)
Creating Classes and Objects
Defining Instance Methods
Using the self Keyword
Constructors (__init__())
Creating Multiple Objects
Storing and Displaying Object Data
Comparing Python OOP concepts with C++
Files Included
class & obj 1.py – Basic class and object example.
classes and obj 2.py – Creating multiple objects.
class and obj 3.py – Object methods and data input.
class and obj 4.py – Displaying object information.
class and obj 5.py – Advanced class and object example.
int coon 1.py – Introduction to constructors (__init__()).
int con 2.py – Constructor with user input.

Learning Outcomes

After completing these programs, I learned how to:

Create classes and objects in Python.
Initialize object data using constructors.
Use the self keyword to access instance variables and methods.
Create and manage multiple objects.
Organize code using Object-Oriented Programming principles.
Understand the similarities and differences between Python and C++ OOP.
Repository Purpose

This repository serves as a practical record of my Week 3 - Day 1 learning activities and contains all the programs developed while studying the basics of Object-Oriented Programming in Python.
